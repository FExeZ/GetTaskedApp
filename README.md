# GetTaskedApp

## Descripción

GetTaskedApp es una aplicación de gestión de tareas desarrollada con **React** para el frontend y **Spring Boot** con **PostgreSQL** para el backend. Permite a los usuarios crear, actualizar y visualizar tareas de manera sencilla y eficiente. La aplicación es totalmente responsiva, lo que garantiza una experiencia de usuario óptima en dispositivos móviles y tabletas.

## Características

- **Crear Tareas**: Permite a los usuarios crear nuevas tareas con un título, descripción, fecha de expiración y estado de completado.
- **Actualizar Tareas**: Los usuarios pueden seleccionar una tarea existente y actualizar sus detalles.
- **Visualizar Tareas**: Muestra una lista de tareas organizadas en tarjetas, con información clara sobre cada tarea.
- **Paginación**: Las tareas se dividen en páginas, mostrando un número limitado por página para una navegación más fácil.
- **Responsividad**: La interfaz de usuario se adapta a diferentes tamaños de pantalla, ofreciendo una experiencia fluida en dispositivos móviles y de escritorio.

## Tecnologías Utilizadas

- **Frontend**: React, HTML, CSS
- **Backend**: Spring Boot
- **Base de Datos**: PostgreSQL
- **Control de Versiones**: Git, GitHub
